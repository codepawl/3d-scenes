# S24 — Ferrofluid Magnet

A pool of black ferrofluid rests on a glass plate while a nickel magnet slides underneath; as it passes, the fluid heaps into a mound and erupts into a hexagonal crown of glossy spikes that tracks the magnet and collapses behind it. The whole picture is a single GLSL fragment shader in three.js (WebGL2) that sphere-traces a signed distance field: a height-field pool smooth-unioned with exact cones on a hex lattice whose heights come from a lagged dipole-like field, shaded as a near-black dielectric with Fresnel reflections of a procedural softbox studio, a secondary march for spike-to-spike reflections, SDF soft shadows and AO, plus an analytic glass plate, magnet and floor. Run it with `cd source && npm install && npm run dev`; `render.mp4` is a 6 s capture made with `node scripts/capture.mjs` (see `source/README.md`), and `bash smoke_test.sh` builds the project and checks the video.
