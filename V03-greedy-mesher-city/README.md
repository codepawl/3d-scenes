# V03 — Greedy Mesher City

A procedural blocky city at dusk. The camera cranes up an avenue toward a low orange sun. As the sky slides into blue hour and the stars come out, street lamps switch on and windows light up room by room. The source of truth is a 192x96x192 `Uint8Array` voxel grid. A seeded generator writes roads, curbs, lane dashes, parks with voxel trees, lamp posts, and buildings into it: four facade window styles, setback tiers, parapets, AC units, water towers, and antennas with blinking beacons. A hand-written chunked greedy mesher (32^3 chunks) turns the grid into about 78k triangles. Each face carries four packed per-vertex ambient-occlusion values, and faces only merge when both the block type and all four AO values match, so AO survives greedy merging. The quad diagonal is flipped to keep AO isotropic. Lighting is a patched three.js Lambert material with a shadow-casting dusk sun, a hemisphere sky and a shader gradient sky dome, plus fog, bloom and MSAA. Window emission is decided per voxel cell in the fragment shader from an integer hash of the voxel coordinate, so merged window quads still switch on one room at a time.

**Run:** `cd source && npm install && npm run dev`. Re-capture the video with `npm run capture` (needs Chrome and ffmpeg). Run `bash smoke_test.sh` to check the build and the video.
