# V07 Biome Ring

A floating voxel ring of land around a lagoon, divided into a dune desert with banded mesas, a snowy tundra with pines and ice sheets, and a rain-soaked wetland of pools, reeds and willows. Each biome has its own weather made of moving voxels: wind-blown sand hops along the ring, snow drifts down, and rain streaks fall and splash. A single `Uint8Array` voxel grid is the source of truth. A custom chunk mesher (face culling, per-vertex AO, per-voxel colour variation) builds the terrain and water from it. The weather particles collide against that grid, and snow and sand write new voxels back into it, which triggers a live re-mesh of the affected chunks. Surface wear, grain, cracks and roughness variation come from a MeshStandardMaterial shader patch. Run it with `cd source && npm install && npm run dev`. `npm run capture` re-renders `render.mp4` deterministically through headless Chrome and ffmpeg.
