# V06-waterfall-cave

A voxel cave, viewed from inside, where a river enters through a sunlit back tunnel and drops over three undercut stone terraces into a deep pool. Foam cubes tumble off every lip and burst up at each impact, and mist cubes rise and drift through a shaft of sunlight from a skylight. The voxel grid is the source of truth. A procedurally generated 48×48×64 material grid holds the rock, and a parallel per-cell water-mass field is stepped by a mass-conserving cellular automaton (down / spread / pressure-up, double buffered) at 60 Hz. Two meshers written for this project render it: a face-culled rock mesh with per-vertex AO and wetness/moss baked from the settled water, and a water mesh rebuilt every frame with smoothed surfaces and fall/foam attributes. Foam and mist are instanced cubes spawned from the flux field. To run it: `cd source && npm install && npm run dev`. `npm run capture` re-renders `render.mp4`, and `bash smoke_test.sh` builds the project and verifies the video.
