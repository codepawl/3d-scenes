# S22 · Volumetric Cumulus

The camera skims low over open ocean beneath a field of cumulus while the sun drops from about 15° to 3° into golden hour. Backlit clouds pick up silver edges, light shafts fan out under the cloud base, and the clouds cast moving shadows that cross the water. Two full-screen GLSL passes in three.js (WebGL2) produce every pixel, with no textures, meshes or voxel grids. The first pass ray-marches the clouds through a curved-earth slab. Its density is a 2D weather fbm, shaped by a height profile and eroded by billowy 3D value noise. Lighting combines a sun-ward light march, multiple-scattering octaves, a dual-lobe Henyey-Greenstein phase function and a powder term. The same pass marches the air below the base to compute crepuscular shafts. It also traces mirrored rays so the clouds reflect in the sea. The second pass composites an analytic Rayleigh/Mie sky driven by Kasten-Young air mass. It adds the ocean, built from footprint-filtered directional waves with Fresnel reflection and a Beckmann sun glint, then applies aerial perspective, ACES tonemapping and dither. To run it: `cd source && npm install && npm run dev`. `npm run capture` re-renders `render.mp4` and needs ffmpeg plus a Playwright Chromium. `bash smoke_test.sh` builds the project and checks the video.
