# V11-voxel-forge

A blacksmith's hammer strikes a glowing billet on an anvil in a dark voxel smithy; every blow throws a spray of instanced voxel sparks that bounce off the anvil and floor, and over the 6-second loop the billet cools from white-hot through yellow and orange to a dull red. Everything is driven from voxel grids: the room, anvil, forge and hammer are `Uint8Array` grids turned into geometry by a hand-written face-culling mesher with per-vertex ambient occlusion, while the billet is a simulated grid holding occupancy and temperature per voxel — heat conducts between neighbours and radiates from exposed faces, and each hammer blow edits the grid by squeezing the top voxels out to the sides so the bar spreads; the billet is drawn as an `InstancedMesh` whose per-instance emission comes from an incandescence ramp, with bloom and ACES tone mapping in three.js (WebGL2). To run it: `cd source && npm install && npm run dev`; `npm run capture` re-renders `render.mp4`, and `bash smoke_test.sh` builds the project and checks the video.
