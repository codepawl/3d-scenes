# S25: Oil Slick Puddle

A rain-soaked asphalt lot at dusk. A shallow puddle holds a film of spilled oil, and every raindrop sends rings across it that stretch and squeeze the film, so the rainbow bands slide and reform. Everything is one GLSL `ShaderMaterial` on a single plane; there are no textures. Film colour comes from physically based thin-film interference: the Airy reflectance of an oil layer (n=1.47) on water (n=1.33), s and p averaged, evaluated at 16 wavelengths and folded to RGB with an analytic CIE colour-matching fit. Film thickness is a slowly rotating, domain-warped fbm field. Each analytic ring wave packet radially displaces and thins that field, so the colour bands move with the ripples. A heightfield against a fixed water level gives the puddle its ragged shore. The procedural asphalt has aggregate, sand, cracks, tar stains, a chipped paint line and varying wetness and roughness, and it reflects an analytic street environment (skyline, lit windows, a sodium lamp). Instanced streaks add falling rain. The scene renders to a HalfFloat target with ACES tonemapping and dithering.

Run it with `cd source && npm install && npm run dev`. See `source/README.md` for controls and capture. `render.mp4` is the 6 s capture. `smoke_test.sh` builds the project and validates the video.
