<h1 align="center">3d-scenes</h1>

Shader studies, voxel studies and full 3D scenes by CodePawl, built with Claude in Claude Code. Each folder has its own
`README.md` with what it is, how it works and how to run it, and a `CREDITS.md` or `SOURCES.md` for third-party files.
For the pieces posted on [@anxuanng](https://x.com/anxuanng), see [codepawl/3d-builds](https://github.com/codepawl/3d-builds).

## Shader studies

Each one is a three.js app where the look comes from GLSL, with a short `render.mp4` and a `smoke_test.sh` that builds the
app and checks the video. Run one with `cd <folder>/source && npm install && npm run dev`.
