# S26 — Ink in Water

Two inks, indigo-black and carmine, drop into a glass tank of water on a worn concrete slab. Each drop rolls up into a vortex ring, sinks as a heavy plume and curls into tendrils that spread across the floor of the tank. Behind the ink is a GPU stable-fluids solver written as three.js `RawShaderMaterial` passes: RK2 semi-Lagrangian advection, negative ink buoyancy, vorticity confinement, divergence, a 36-iteration Jacobi pressure solve and gradient subtraction, with the dye advected on a grid 3x finer than the velocity. A single fullscreen fragment shader ray-traces the scene: Fresnel reflection and Snell refraction through the tank, total internal reflection under the water surface, smudged and limescaled glass, and procedural concrete and plaster. The 2D dye field is lifted into a volume procedurally rather than stored in a voxel grid: a blurred copy of the dye sets the plume's thickness, and 3D noise warps every depth slice. The ink is then ray-marched with Beer-Lambert absorption, Henyey-Greenstein single scattering and a short shadow march toward the key light, and its coloured shadow and caustics fall on the table.

Run it: `cd source && npm install && npm run dev`. To re-render the video, run `cd source && npm run capture` (writes `../render.mp4`). To check the build and the video, run `bash smoke_test.sh`.
